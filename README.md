# Nymind’s IPTV TEST 0.8.1

Rozbal balíček a nahraj jeho obsah do stávajícího repozitáře testovacího IPTV modulu. Zachovej složku app vedle package.json. Potom testovací modul znovu otevři v TizenBrew. Na obrazovce se zobrazí TIZEN TEST 0.8.1.

Žlutý rámeček označuje výběr. Po startu je vybrané M3U playlist. OK otevře formulář. V něm šipky nahoru a dolů procházejí položky, OK na textovém poli zahájí psaní. Soukromou adresu zadej přímo na televizi.

OK na poli M3U URL otevře vestavěnou klávesnici. Hotovo přesune výběr na Načíst kanály.
